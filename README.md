A short, funny rant about a small everyday annoyance, written as two sentences on one line (under 400 characters). The program validates the rant and writes it to `entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/angry-judge-rant-out node main.ts
```

This writes `entry.txt` (the rant plus a trailing newline) into the output directory.
